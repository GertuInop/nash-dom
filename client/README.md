# Наш Дом — Frontend

Frontend-приложение для жителей МКД и сотрудников УК в стилистике мессенджера MAX.

## Возможности

### Житель
- Вход / отдельная регистрация
- Выбор дома
- Лента событий (пустая до создания тем)
- Чаты: общий, с УК, тематические (пустые)
- Создание тем (с модерацией)
- Профиль, история обращений

### УК
- Отдельная регистрация (название УК + ФИО + телефон)
- Панель заявок (статусы: Новая / В работе / Выполнена)
- Чаты с жителями

### Модерация (мок нейросети)
При отправке сообщения и создании темы проверяется:
- Запрещённые слова и оскорбления
- Спам / реклама / внешние ссылки
- Избыточные ЗАГЛАВНЫЕ
- Слишком длинный текст

Нарушение → сообщение скрывается, пользователь видит причину.

## Демо-вход

1. **Житель:** любой телефон (не на 1) + пароль ≥ 4
2. **УК:** телефон, оканчивающийся на `1` + пароль ≥ 4  
   Или отдельная регистрация УК.

## Запуск

```bash
npm install
npm run dev
```

http://localhost:5173
