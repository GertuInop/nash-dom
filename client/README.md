# Наш Дом

Frontend мини-приложения MAX. Данные идут в общую MySQL через API бота (`/server`), а не в localStorage.

## Пути на проде (через Caddy в `bot/`)

| Путь | Кто ходит | Куда |
|------|-----------|------|
| `/` | пользователь / MAX miniapp | этот фронт |
| `/server/*` | фронт | REST API бота |
| `/bot` | MAX platform | webhook бота |

## Запуск локально (без Docker)

1. Поднимите MySQL и API из `../bot`.
2. Здесь:

```bash
npm install
npm run dev
```

Прокси Vite: `/server` → `http://127.0.0.1:3080`.

## Запуск в Docker (отдельно от бота)

Сначала API бота на **3080**.

```bash
cp .env.example .env
docker compose up --build -d
```

Клиент: **http://localhost:5173**

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `WEB_PORT` | Порт на хосте | `5173` |
| `API_UPSTREAM` | Куда nginx шлёт `/server` | `http://host.docker.internal:3080` |

Рекомендуется общий запуск из `../bot` (`docker compose up`) — Caddy отдаёт `/`, `/server`, `/bot` с одного домена.

## Демо-вход

Пароль от 4 символов. Можно не регистрироваться — аккаунт создаётся в БД.

| Роль | Как определяется | Пример |
|------|------------------|--------|
| Житель | телефон **не** оканчивается на `1` | `+79001234567` / `1234` |
| УК | телефон оканчивается на `1` | `+79001234561` / `1234` |
