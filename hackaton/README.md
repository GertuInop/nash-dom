# Наш Дом

Frontend мини-приложения MAX. Данные идут в **общую MySQL** через API бота (`/api`), а не в localStorage.

## Запуск

1. Поднимите MySQL и API из `../bot` (см. корневой README).
2. Здесь:

```bash
npm install
npm run dev
```

Прокси Vite: `/api` → `http://127.0.0.1:3080`.

## Демо-вход

Пароль от 4 символов. Можно не регистрироваться — аккаунт создаётся в БД.

| Роль | Как определяется | Пример |
|------|------------------|--------|
| Житель | телефон **не** оканчивается на `1` | `+79001234567` / `1234` |
| УК | телефон оканчивается на `1` | `+79001234561` / `1234` |

## Что на сервере

- Пользователи, дома, чаты, темы, сообщения
- Заявки (`requests`) — те же, что видит бот
- Работы по подъездам (`entrance_works`)
- Модерация сообщений на API

## Роли

**Житель:** лента, темы, чаты, профиль, обращения.  
**УК:** панель заявок, статусы, чаты, скрытые сообщения.
